# 🖥️ sistema

Auditoría de seguridad del sistema Windows: configuración SSH, reglas de firewall y detección de usuarios sospechosos.

| Script | Descripción |
|---|---|
| `auditar_ssh.ps1` | Verifica configuración del servidor OpenSSH |
| `firewall_status.ps1` | Estado del firewall y reglas activas |
| `usuarios_sospechosos.ps1` | Revisa usuarios locales con privilegios elevados |
