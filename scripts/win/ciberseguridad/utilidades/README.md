# 🔐 utilidades

Utilidades criptográficas: generación de contraseñas seguras, verificación de hashes y cifrado AES-256.

| Script | Descripción |
|---|---|
| `generar_password.ps1` | Genera contraseñas con distintos perfiles de seguridad |
| `verificar_hash.ps1` | Calcula y compara hashes MD5/SHA1/SHA256/SHA512 |
| `cifrar_archivo.ps1` | Cifra y descifra archivos con AES-256 |
