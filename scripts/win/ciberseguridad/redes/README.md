# 🌐 redes

Herramientas de análisis de red: escaneo de puertos, resolución DNS, conexiones activas y geolocalización IP.

| Script | Descripción |
|---|---|
| `escaneo_puertos.ps1` | Escaneo de puertos TCP con Test-NetConnection |
| `analisis_dns.ps1` | Resolución DNS completa y análisis de registros |
| `conexiones_activas.ps1` | Vista de conexiones TCP/UDP activas con procesos |
| `geoip.ps1` | Geolocalización de IPs con ip-api.com |
