# 🛡️ ciberseguridad

Scripts de seguridad ofensiva y defensiva para Windows: análisis de redes, auditoría web, revisión del sistema y utilidades criptográficas.

| Script | Descripción |
|---|---|
| `redes/` | Escaneo de puertos, DNS, conexiones activas, GeoIP |
| `web/` | Cabeceras HTTP, certificados SSL, subdominios |
| `sistema/` | SSH, firewall, usuarios sospechosos |
| `utilidades/` | Contraseñas, hashes, cifrado AES |
