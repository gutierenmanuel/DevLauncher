# Task 01 – Estructura y READMEs

**Estado:** ⬜ pendiente  
**Depende de:** nada  
**Bloquea:** task_02, task_03, task_04, task_05

## Objetivo

Crear la carpeta raíz `ciberseguridad/` y las cuatro subcarpetas con sus `README.md` correctamente formateados para que el launcher detecte icono y descripción.

## Archivos a crear

```
scripts/linux/ciberseguridad/
  README.md          → # 🛡️ ciberseguridad
  redes/
    README.md        → # 🌐 redes
  web/
    README.md        → # 🕸️ web
  sistema/
    README.md        → # 🖥️ sistema
  utilidades/
    README.md        → # 🔐 utilidades
```

## Formato de cada README

```md
# <emoji> <nombre_carpeta>
Descripción corta de lo que contiene.
```

## Criterio de éxito

- El launcher muestra la categoría `ciberseguridad` con icono 🛡️.
- Las subcarpetas aparecen navegables con sus propios iconos.
